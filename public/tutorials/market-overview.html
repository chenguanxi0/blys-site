🧭 短线核心：市场大局观

不盯单只票的涨跌，先看清自己站在什么样的「天时、地利」里。约 15 分钟阅读

👁 浏览 -- 次

🎯 本课程要解决的核心问题

短线客最容易犯的错：一开盘就盯着单只股票涨跌，忘了自己正站在什么样的「天时、地利」里。

前置问题对应动作
现在这盘棋，能不能下？重仓 / 轻仓 / 空仓？
钱在往哪个方向流？主线在哪？
我在周期的什么位置出手？启动 / 主升 / 分歧 / 退潮？

一句话：大局观决定"仓位与方向"，技术买点只决定"进场位置"。顺序不能反。

🌏 什么是"市场大局观"

先看「天」 ➜ 再看「地」 ➜ 最后看「人」

  • 🌤️ 看天 — 宏观 + 政策：市场水位（钱多不多、风往哪吹、适不适合做多）
  • 🌊 看地 — 周期 + 情绪：仓位大小（现在该几成仓、处于情绪哪一阶段）
  • 🧍 看人 — 产业链 + 资金 + 个股：做哪个方向（选哪条线、挑哪只票）
⚠️ 大局观 ≠ 看大盘指数涨跌。指数红绿只是结果，真正的"大局"是：钱多不多、情绪好不好、主线清不清晰。

🌤️ 看"天"：宏观与政策（决定市场水位）

每天花 3 分钟，快速判断三件事：

💰 货币政策 — 钱多不多

降息/降准/MLF/逆回购方向；国债收益率下行、资金面宽松 → 易涨；钱紧利率上行 → 难涨、控仓。

📜 政策方向 — 风往哪吹

盯政治局会议、发改委、工信部重点方向：新质生产力、AI、半导体、低空经济、消费、机器人……

🌍 外部环境 — 影响情绪

美股、人民币汇率、大宗（原油/铜/黄金）。多属"情绪扰动"，非 A 股主线本因。

结论模板 —— 每天给自己一句话定性：
  • 偏多 · 可做多 — 货币宽松 + 政策友好 → 找主线，上仓位
  • 震荡 · 轻仓 — 货币中性 + 区间震荡 → 高抛低吸，控仓
  • 偏空 · 防守 — 收紧 + 高位放量杀跌 → 少动甚至空仓

🌊 看"地"：情绪周期四阶段（决定仓位）

短线大局观的核心就是情绪周期。市场像潮水有涨落，分四个阶段：

① 启动期
仓位：1–2 成
② 主升期
仓位：5–8 成
③ 分歧期
仓位：3 成
④ 退潮期
仓位：≤2 成或空仓

① 启动期（仓位 1–2 成）

  • 连板开始增多、跌停变少
  • 龙头率先涨停，新方向冒头
  • 操作：小仓试错，错了止损不恋战
  • 心态：宁错过，不买错
铁律口诀：主升敢重仓，退潮绝不硬扛。

辅助判断信号

信号怎么读含义
昨日涨停今日表现正 = 接力赚钱效应好；负 = 打板生态恶劣
涨停家数 vs 跌停家数跌停激增 = 风险 > 机会
连板高度高度被压制 = 情绪冰点 / 退潮

🧍 看"人"：产业链、估值与资金（决定方向）

🌱 行业生命周期 — 成长期 vs 衰退

成长期（AI、机器人、储能、半导体）→ 易出大行情、敢格局；衰退/饱和期 → 多是反弹，快进快出不格局。

📊 估值位置 — 历史分位

PE/PB 历史高位 → 别追；历史低位 → 敢拿，赔率好。

💸 资金流向 — 钱去哪势就在哪

北向、两融、板块成交额。持续放大 = 真主线；缩量轮动、一日游 = 小热点，不重仓。

🔥 如何锁定当下热点（每天 5 分钟）

真热点 ≠ 零散几个涨停。真热点 = 政策/事件催化 + 板块效应 + 资金持续流入。

看什么问自己
1板块涨幅榜谁在最前面？
2涨停梯队哪个板块涨停最多、连板最多？
3板块成交额是否持续放大？（没量走不远）
4催化消息为什么涨？政策/订单/技术/涨价？
四字诀：
抓主线 — 有持续性的大方向，不是一日游
看催化 — 上涨的"理由"够不够硬
认龙头 — 板块里辨识度最高、最先表态的票
分强弱 — 只做前排，后排跟风性价比低

⚡ 操作顺序铁律（刻进肌肉记忆）

第一步 ① 定仓位 → 现在能不能做？（看天 + 看地）
第二步 ② 定方向 → 做什么？（政策 + 产业 + 资金）
第三步 ③ 选个股 → 做哪只？（主线龙头 / 中军）
❌ 误区：很多人反过来 —— 先刷到一只票，再去找"它为什么涨"的理由。这是被动追涨，容易被情绪带着走。

✅ 实战：每日盘前检查清单

开盘前逐项打钩，顺序就是上面教的大局观流程。点击条目即可勾选：

  • 天时：货币/政策定性——今天偏多、偏震荡、还是偏空？
  • 周期定位：当前处在启动 / 主升 / 分歧 / 退潮哪一阶段？
  • 仓位上限：据此阶段给自己定一个上限（如退潮期 ≤ 2 成）。
  • 主线确认：今天最强板块是谁？有无持续催化？
  • 龙头锁定：该板块前排是谁？封单/换手是否健康？
  • 风险信号：跌停家数是否激增？高位股是否开始杀？
  • 交易计划：买点后置（确认强度再出手），卖点提前（有利润先锁定）。

⚠️ 新手常见误区

  1. 只看个股不看势 — 票再好，退潮期也容易被拖下水。
  2. 缩量反弹中追高 — 所有缩量反弹都可能是诱多，等放量确认。
  3. 盲目接力中位股 — 3–4 板最易吃面：要么做前排龙头，要么做低位试错。
  4. 老题材反抽当新主线 — 退潮期老题材回流多是出货，不是机会。
  5. 把"对与错"割裂 — 盈亏对错交替连续，用仓位和纪律应对，不靠预测。
  6. 顺序颠倒 — 先瞄到票再找理由 = 被动追涨，务必先定势再选股。

💡 课堂思考 / 练习

先自己写答案，再点"看参考答案"。

1. 今天盘面是"启动期"还是"退潮期"？列出你的 3 条判断依据。
看：①连板高度与数量（多在增加=启动，在压缩=退潮）；②跌停家数（激增=退潮）；③昨日涨停今日溢价（负=退潮）。用这三条各找 1 个证据，再下结论。
2. 某板块涨停 8 家但成交额没放大、次日无新催化——这是真主线还是一日游？为什么？
更偏一日游。真主线 = 催化 + 板块效应 + 资金持续。缺"成交额持续放大"和"持续催化"两条，涨停多可能是情绪脉冲，次日易分化回落，不宜重仓。
3. 当前你的仓位上限应该定几成？写出"天/地/人"三项依据。
先定天（货币/政策偏多→可多，偏空→压仓）、再定地（周期阶段→启动1-2成/主升5-8成/分歧3成/退潮≤2成）、最后看人（主线清晰度）。三者取最谨慎的那个作为上限。
4. 找一只你熟悉的高辨识度龙头，描述它在主升期 vs 退潮期分别该怎么处理。
主升期：敢于上仓位、沿趋势持有、只做前排；退潮期：不硬扛、冲高即减/清、宁可空仓等下一轮启动。同一只票，周期位置不同，操作完全相反。

📋 关键口诀卡（建议保存）

先看天，再看地，最后看人。

货币宽松+政策友好=可做多；收紧+高位杀=防守。

启动试错、主升重仓、分歧降仓、退潮空仓。

主升敢重仓，退潮绝不硬扛。

真热点 = 催化 + 板块效应 + 资金持续。

抓主线、看催化、认龙头、分强弱。

先定仓位，再定方向，最后选股。

在周期末端，活下来比赚钱更重要。
